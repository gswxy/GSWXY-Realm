# 常见问题（FAQ）

## 下载与数据包

**Q：客户端数据下载很慢 / 卡住不动？**
「数据」页默认"自动选择"线路：会实测官方与各镜像的真实连通速度后择优，卡死线路 30 秒无数据即自动换线并在页面底部显示每条线路的尝试结果。也可以手动切换某条线路，或取消后重试（同线路断点续传，已下载部分不会浪费）。

**Q：GitHub 完全连不上怎么办？**
在任何电脑（手机热点也行）从官方发布页下载 `Data.zip`，放进 NAS 应用数据目录的 `downloads/manual/` 文件夹，回「数据」页点「扫描并导入」。校验规则与在线下载完全一致。

**Q：为什么服务端要用 enUS 数据包？我的中文客户端还能玩吗？**
能。服务端 DBC（游戏基础数据文件）按 AzerothCore 兼容要求使用 enUS 版；这与客户端语言无关——中文客户端照常连接，游戏内中文由数据库中文化和账号设置提供。**不要**把中文客户端 Data/zhCN 目录拷给服务端。

**Q：导入 Data.zip 提示校验失败？**
说明文件不是与本发行版 Core 版本匹配的官方 enUS 数据包（大小或 SHA-256 不符）。请到 wowgaming/client-data 的 v20.0 Release 重新下载完整文件，不要用第三方修改包或中文客户端数据替代。

**Q：FPK 有国内下载吗？**
「版本」页检查更新时，若国内加速线路实测可用（文件存在且大小与官方一致）会显示「国内下载」按钮；没有就只有 GitHub 官方地址，不会显示假的下载入口。两种来源文件完全一致，校验方法见 README「下载线路与国内网络」。

## 安装与初始化

**Q：安装向导里填的密码/服务器名/机器人数量没生效？**
1.1.0 之前的版本存在此缺陷（向导参数未被读取）。1.1.0 起安装即生效：用向导密码登录即可；若想改，登录后概览页可改名称，「机器人」页可调数量。

**Q：初始化跑到一半失败 / 重启了，会破坏数据吗？**
不会。每个步骤完成即落盘，重试从第一个未完成步骤继续；已导入的数据不会重复导入。

**Q：初始化显示完成，但启动 WorldServer 失败？**
「初始化完成」指数据库就绪；WorldServer 还需要客户端数据。到「数据」页下载（约 1.1 GB，官方源 → 公共代理自动回退、断点续传），或用 NAS 本地导入：把官方 `Data.zip` 放进应用数据目录的 `downloads/manual/` 文件夹，点「扫描并导入」。

**Q：提示端口被占用？**
「服务器」页自检会标明端口（3724 登录 / 8085 世界 / 18700 管理）。停掉 NAS 上占用端口的其他应用，或在「配置 → 常用/高级」改端口后同步修改客户端连接方式。

**Q：应用图标/名称还是旧的？**
升级安装 1.1.0 后桌面名称变为「艾泽旅伴」、图标更换为传送门样式；若桌面缓存未刷新，重新打开应用中心或刷新桌面。应用数据目录与账号数据不变。

## 连接与游玩

**Q：怎么查看 NAS 的 IP？**
fnOS 桌面 → 设置 → 网络，或路由器设备列表。「服务器」页也会自动检测局域网地址并展示。

**Q：realmlist 应该填什么？**
- 局域网：`set realmlist <NAS 内网 IP>`（「概览」页直接给出）
- 公网：`set realmlist <公网 IP 或域名>`，需路由器放行 3724/8085 并在「服务器」页把公网地址填入手动设置
- 最省事：下载「客户端启动器 .bat」放进客户端文件夹双击

**Q：登录后服务器列表是空的 / 连不上？**
1. 确认 AuthServer/WorldServer 都显示「运行中 · 端口就绪」
2. 客户端必须是 3.3.5a（12340）
3. realmlist 指向的地址要和「服务器」页生效地址一致
4. 公网访问检查路由器端口转发与防火墙；注意自动检测的"公网 IP"只代表出口地址，不等于外网可达

**Q：怎么创建账号 / 给账号 GM 权限？**
「账号」页 → 创建账号（表单里直接选 GM 等级 0–3）；已有账号点行内「GM 等级」随时修改。GM 等级：0 玩家 / 1 协理员 / 2 游戏管理员 / 3 开发者。

**Q：机器人会说中文吗？**
会。本应用创建的账号 locale 已设为 zhCN，配合内置中文数据，机器人聊天、任务、喊话均为中文。

## 机器人

**Q：机器人数量多少合适？**
经验值：每 CPU 核 20–40 个在线机器人（4 核 NAS 建议 ≤150）。负载高时切换「低性能」模板或在「常用设置」调小数量，重启 WorldServer 生效。

**Q：应用模板后没变化？**
所有 `AiPlayerbot.*` 配置都需要重启 WorldServer。模板应用后页面会提示；到「服务器」页重启 WorldServer 即可。

**Q：随机机器人账号会占我创建的账号名吗？**
随机机器人使用独立前缀账号（默认 `RNDBOT*`），与玩家账号互不干扰；统计页的"真实玩家 / 机器人"也是按这个口径区分的。

## 配置

**Q：改了配置没生效？**
绝大多数配置需重启 WorldServer（界面会标注「需重启」）。数据库连接等敏感项由系统管理，不在编辑范围。

**Q：原始编辑器会把文件改坏吗？**
编辑器只写"用户覆盖层"，坏一行最多影响该项；「高级设置」里可逐项还原默认，或整文件恢复默认。保存时服务端会校验类型。

**Q：想开十倍经验？**
「配置 → 常用设置」直接有经验/掉落倍率；改完重启 WorldServer。

## 备份与数据

**Q：备份包含机器人吗？**
包含。1.1.0 起备份完整覆盖 acore_playerbots 库（机器人绑定、自定义策略等）+ 账号 + 角色 + 世界中文化表 + 用户配置与状态。客户端数据不备份（可随时重新下载）。

**Q：卸载会删数据吗？**
默认保留全部数据。只有卸载向导里明确选择"同时删除所有服务器数据"才会清除 `var/` 下的数据。

**Q：能在另一台 NAS 上恢复吗？**
可以，但注意：目标机器需先完整安装同版本（或更新版本）应用并完成初始化，再用备份恢复。恢复会自动保留目标机器自身的数据库端口等环境差异；备份若来自更新版本会被拒绝，请先升级应用。

## 性能与故障

**Q：WorldServer 启动很慢？**
首次启动要加载数据库结构更新与地图数据，几分钟属正常；「概览」会显示"启动中 · 端口未通"，端口就绪后自动变绿。

**Q：进程崩溃会反复重启吗？**
守护进程带指数退避（2s 起步、上限 5 分钟、连续 10 次后停止自动重启并标记故障），避免雪崩；标记故障后到「服务器」页手动启动。

**Q：日志里能看到密码吗？**
不能。审计与日志均不记录密码；数据库凭据文件权限 0600 且不在日志范围。诊断包导出同样不含敏感信息。

## 其他

**Q：支持 ARM（如飞牛 ARM 机型 / N1 盒子）吗？**
不支持。AzerothCore 二进制与 MySQL 运行时均为 x86_64。

**Q：为什么用 MySQL 8 而不是 MariaDB？**
mod-playerbots 分支核心按版本字符串比较，MariaDB（11.x）会被判定低于要求而拒绝启动；MySQL 8.0.46 minimal 为验证过的锁定版本。

**Q：数据库能在外部访问吗？**
内置 MySQL 仅监听 127.0.0.1 随机高位端口，凭据随机生成且不展示，外部无法直接访问。
