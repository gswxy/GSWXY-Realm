# 部署指南（fnOS 实机）

> 面向普通 fnOS x86_64 用户。全程不需要 SSH / Docker / MySQL / SQL。

## 1. 安装

1. 从 GitHub Releases 下载 `GSWXY-Realm-x.y.z-x86_64.fpk`（及 `.sha256`，可自行校验）
2. fnOS 桌面 → 应用中心 → 右上角「手动安装」→ 选择 fpk
3. 安装向导中填写：
   - 游戏服务器名称（默认 `GSWXY Realm`）
   - 管理界面密码（≥8 位，用于登录管理界面）
   - 初始机器人数量（10–500，之后可随时改）

## 2. 首次初始化

打开 GSWXY Realm 图标（或浏览器访问 `http://<NAS IP>:18700`）：

1. 用安装向导里设置的管理密码登录
2. 概览页 →「开始初始化」，依次自动完成：
   - 运行环境检查
   - 内置数据库初始化（随机密码自动生成，凭据文件 0600，仅本机监听）
   - 数据库导入：上游基础库 → 更新 → Playerbots 模块数据
   - 中文数据导入（GSWXY Locale zhCN，内置随包）
   - Realm 注册
3. 「数据」页 → 下载 AC 客户端数据（v20，约 1.1 GB）
   - 下载器自动按 官方源 → 公共代理 顺序尝试，支持断点续传与 SHA-256/大小校验
   - 若网络受限：在本地电脑从官方 Release 下载 `Data.zip`，用「手动导入」上传
4. 初始化完成 →「启动全部」

## 3. 客户端连接

- 3.3.5a (12340) 客户端 `realmlist.wtf` 改为：`set realmlist <NAS的IP>`
- 用「账号」页创建的账号登录（管理页面创建账号默认 locale=zhCN，机器人会说中文）
- 公网开服：路由器端口转发 3724/TCP 与 8085/TCP；realmlist 填公网地址

## 4. 日常管理

| 页面 | 功能 |
| --- | --- |
| 概览 | 服务状态、在线人数（真人/机器人）、一键启动/安全停止 |
| 服务器 | 启动前自检（逐项给出失败原因与修复建议）、进程重启、Realm 名称 |
| Playerbot | 统计与分布、五个配置模板（应用前展示 diff） |
| 账号 | 创建/改密/GM 等级/封禁/解封/查看角色 |
| 配置 | 1516 个配置项（三层模型）、原始编辑器、恢复默认 |
| 数据 | 客户端数据版本状态、下载/取消/手动导入 |
| 日志 | Manager/审计/三进程/AC 日志的查看与过滤 |
| 备份 | 一键备份、恢复（恢复前自动先备份当前状态） |
| 版本 | Core/模块 commit、数据版本、Locale 版本、构建信息 |

## 5. 数据与安全

- 持久数据在 `var/`（fnOS `@appdata`）：升级、卸载均默认保留
- 数据库仅监听 `127.0.0.1` 随机高位端口；root 密码随机生成，文件权限 0600
- 所有管理操作写审计日志；登录接口限速；会话 HMAC 签名 + CSRF 校验
- 控制台命令只转发到 WorldServer stdin，无 shell 参与

## 6. 常见问题

- **初始化卡在客户端数据**：可跳过（稍后下载）；不影响数据库初始化
- **端口被占用**：「服务器」页自检会标明哪个端口被谁占用
- **机器人数量调整**：Playerbot 页或配置页 `AiPlayerbot.*`，重启 WorldServer 生效
- **升级 FPK**：直接安装新版覆盖；数据库与配置自动保留，运行配置自动重新生成
