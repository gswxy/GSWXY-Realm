# 部署指南（fnOS 实机）

> 面向普通 fnOS x86_64 用户。全程不需要 SSH / Docker / MySQL / SQL。

## 1. 安装

1. 从 GitHub Releases 下载 `GSWXY-Realm-x.y.z-x86_64.fpk`（及 `.sha256`，可自行校验）
2. fnOS 桌面 → 应用中心 → 右上角「手动安装」→ 选择 fpk
3. 安装向导中填写（安装即生效，无需再设置）：
   - 游戏服务器名称（默认 `艾泽旅伴`）
   - 管理界面密码（≥8 位，用于登录管理界面）
   - 初始在线机器人数量（10–500，之后可随时改）

## 2. 首次初始化

打开「艾泽旅伴」图标（或浏览器访问 `http://<NAS IP>:18700`）：

1. 用安装向导里设置的管理密码登录
2. 概览页 →「开始初始化」，依次自动完成：
   - 运行环境检查
   - 内置数据库初始化（MySQL 8.0，随机密码自动生成，凭据文件 0600，仅本机监听）
   - 数据库导入：上游基础库 → Playerbots 模块数据
   - 中文数据导入（GSWXY Locale zhCN，内置随包）
   - Realm 注册
   进度逐步落盘，中断后可直接续跑；某步失败会显示原因，修复后重试即可。
3. 「数据」页 → 下载 AC 客户端数据（v20 enUS，约 1.1 GB）
   - 下载线路默认"自动选择"：实测官方 GitHub 与镜像线路速度后择优，卡死/报错自动换线（页面底部显示每条线路的尝试原因）；也可手动指定线路
   - 支持断点续传（取消后同线路重试不浪费已下载部分）、30 秒无数据自动换线、SHA-256/大小校验
   - 大文件推荐 NAS 本地导入：fnOS 文件管理器把**官方 enUS 版** `Data.zip`（wowgaming/client-data v20.0 发布）放入应用共享目录的 `downloads/manual/`，回到页面点「扫描并导入」；中文客户端的 Data 目录不能替代服务端数据包
   - **注意：客户端数据完成前，WorldServer 无法启动**
   - 说明：服务端 DBC 使用 enUS 是运行要求；玩家继续用中文客户端即可，游戏内中文由数据库本地化提供
4. 初始化完成 →「启动全部」→ 等待 WorldServer 端口就绪（首次加载需几分钟）

## 3. 客户端连接

- 3.3.5a (12340) 客户端：
  - 推荐：下载「客户端启动器 .bat」放进客户端文件夹，双击自动改 realmlist 并进游戏
  - 或手动把 `realmlist.wtf` 改为：`set realmlist <NAS的IP>`
- 用「账号」页创建的账号登录（创建时可选 GM 等级，随时可改；账号默认 zhCN，机器人说中文）
- 公网开服：路由器端口转发 3724/TCP 与 8085/TCP，并在「服务器」页把公网地址填入手动设置；管理界面（18700）不建议暴露公网

## 4. 日常管理

| 页面 | 功能 |
| --- | --- |
| 概览 | 总体状态与端口就绪度、在线人数（真人/机器人）、连接指引、初始化进度、最近事件、备份摘要、一键启动/安全停止 |
| 服务器 | 启动前自检、三进程独立重启、WorldServer 控制台、服务器名称、公网/局域网地址、启动器下载 |
| 机器人 | 常用设置直改真实配置、五种玩法模板（应用前展示全部变更）、统一口径统计与分布 |
| 账号 | 创建（含 GM 等级）/ 改密 / GM 修改 / 封禁解封 / 角色列表，全部表单化操作 |
| 配置 | 常用设置 / 高级设置（全部配置项·分组·中文说明）/ 原始编辑器，三层配置模型 |
| 数据 | 客户端数据下载进度、NAS 本地导入、浏览器上传备选 |
| 日志 | 错误/警告过滤、关键字、自动刷新、诊断包导出 |
| 备份 | 手动/每日自动备份、任务进度、恢复（含影响说明与二次确认） |
| 版本 | 组件版本、GitHub 在线更新检查（stable/nightly） |

## 5. 数据与安全

- 持久数据在 `var/`（fnOS `@appdata`）：升级、卸载均默认保留
- 数据库仅监听 `127.0.0.1` 随机高位端口；root 密码随机生成，文件权限 0600
- 所有管理操作写审计日志（密码脱敏）；登录接口限速；会话签名 + CSRF 校验；登出即吊销全部令牌
- 备份完整覆盖账号/角色/机器人数据库与配置，详见 [备份恢复.md](备份恢复.md)
