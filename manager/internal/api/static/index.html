服务器名称与网络地址

Realm 名称会显示在客户端服务器列表；地址留空保存则自动检测。公网地址给外网玩家，本地地址给局域网玩家。

提示：自动检测的"公网 IP"只代表出口地址，不等于外网可达。公网开服需在路由器放行 3724/8085 端口并做好安全策略；管理界面（18700）不建议暴露公网。

客户端启动器

数据

      

        
客户端数据（DBC / 地图 / 建筑 / 寻路）

        
服务端数据包为官方 enUS 版（含 DBC 等基础数据文件），由版本锁定的 SHA-256 校验；中文客户端照常使用，无需改成英文——游戏内中文由数据库本地化提供。请勿用中文客户端的 Data/zhCN 目录替代。

        

        

          
          
          
        

        

        

        

      

      

        
NAS 本地导入（推荐大文件用户使用）

        
用 fnOS 文件管理器把官方 enUS 版 Data.zip（wowgaming/client-data 发布，与服务端 Core 版本匹配）放入应用数据目录的 downloads/manual/ 文件夹，然后点「扫描并导入」。导入与下载使用相同的完整性校验（大小 + SHA-256），中文客户端的数据目录不能替代。
